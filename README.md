# Fulfill — sistem fulfillment Shopee

Aplikasi mandiri baru untuk admin, picker di HP, dan packer di laptop. Backend Node.js + PostgreSQL (Supabase melalui `DATABASE_URL`), antarmuka React, dan video tersimpan di Google Drive melalui OAuth resmi. Tidak menggunakan Google Apps Script.

**Proyek aktif ada di [`fulfillment/`](fulfillment/README.md).** Ikuti panduan di sana untuk instalasi, akun admin pertama, dan koneksi Drive.

File Apps Script sebelumnya dipertahankan di `legacy/apps-script/` sebagai arsip. File tersebut tidak dimuat, dibangun, atau diperlukan oleh aplikasi baru.
